# Amaidhi · அமைதி

A free, private, bilingual (English + தமிழ்) 8-week anger workbook.

- No sign-up, no email: everything a person writes stays on their own device.
- Built on CBT for anger, with public-domain SAMHSA material as the starting structure.

`prototype/index.html` holds three design directions for the home screen (Journal, Guided, Night). Open it in a browser and switch between them with keys 1–3.
