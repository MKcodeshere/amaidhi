# Amaidhi · அமைதி

**Anger is fire. Calm is water.** A free, private, bilingual (English + தமிழ்) anger workbook.

- **SOS mode** (`#sos`): six steps from boiling to calm, built for the moment of rage. Stop (hold 3 seconds), step away (20-minute calm timer), cool your body, breathe (4 in, 6 out), write it instead of sending it, check the heat, then find what is underneath.
- **No accounts, no email, no server.** Everything a person writes stays in their own browser's storage. Quick exit on every screen. One-tap erase.
- **Workbook** (`#workbook`, `#week-0` … `#week-8`): Start + 8 weeks, CBT-based. Each week has Listen (optional audio), Learn, Do (worksheets saved on the phone), Practise (daily tracker) and "Added to your SOS". What people write personalises SOS: reason, warning signs, exit line, top body tools, coping cards, heat-scale examples, repair message.
- **Journal** (`#journal`): SOS sessions, anger log, thought records, heat-check chart, and the locked "don't send it" notes (readable after 20 minutes). Backup/restore as a JSON file.

Static site: `index.html`, `assets/app.css`, `assets/app.js` (landing + SOS), `assets/workbook.js` (workbook + journal). Lesson audio goes in `assets/audio/<en|ta>/start.mp3` and `week1.mp3` … `week8.mp3`; the player appears automatically when a file exists. Images in `assets/img/` were generated with Codex image generation. Hosted on GitHub Pages from `main`.

Amaidhi is a self-help tool, not therapy or emergency care. India: Tele-MANAS 14416 · Emergency 112.
